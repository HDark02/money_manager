# 💰 Money 1% – Gérer son argent comme les riches

## 🚀 Description

**Money 1%** est une application développée avec **KivyMD** qui aide à gérer son argent selon une stratégie utilisée par les personnes financièrement intelligentes et les 1% les plus riches.

Le principe est simple :
👉 Diviser automatiquement ton argent en 4 catégories stratégiques pour créer de la richesse, sécuriser ton avenir et profiter de la vie.

---

## 🧠 Philosophie du projet

Les personnes riches ne dépensent pas leur argent au hasard.

Elles répartissent leurs revenus selon des priorités claires :

* 🔴 **50% – Dépenses (Expenses)**
  Logement, nourriture, transport, factures.

* 🟡 **15% – Urgences (Emergency)**
  Fonds de sécurité pour imprévus.

* 🟢 **25% – Investissements (Investment)**
  Business, crypto, immobilier, actions, formation.

* ⚪ **10% – Loisirs (Fun)**
  Sorties, plaisirs, récompenses.

💡 Cette méthode permet de :

* Éviter les dettes inutiles
* Construire un patrimoine
* Avoir un fonds d'urgence
* Profiter de la vie sans culpabilité

---

## 📱 Fonctionnalités


```bash

```

### 3️⃣ Lancer l'application

```bash

```

## 🎯 Exemple d'utilisation

Si tu entres :
